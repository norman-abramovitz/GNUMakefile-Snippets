# Consumers

Opt-in registry of repositories vendoring these snippets. Add yours by
PR: repo, mount path (where `snippets.sha256` lives), optional notes.
Detailed truth stays in each consumer's manifest — this list records
only what cannot be derived: that you exist and where you mounted.

Honest limits: entries go stale (a sweep flags missing manifests rather
than guessing), private repos cannot be swept, and the list is a floor,
not a census.
